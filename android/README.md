# Android App (Native Java)

Package: me.karthikeyang.handcricket

## Open in Android Studio
1. Open Android Studio.
2. Select "Open" and choose the `android` folder.
3. Let Gradle sync.

## Build APK
- Debug APK: Build > Build Bundle(s) / APK(s) > Build APK(s)
- Release APK: Build > Generate Signed Bundle / APK

## API Base URL
The app is configured to use:
```
https://handcricket-game.karthikeyang.me
```
Update `API_BASE_URL` in `MainActivity.java` if needed.
